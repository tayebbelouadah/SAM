# نظام إدارة ومتابعة غيابات الطلبة

تطبيق ويب مخصص للاستعمال الإداري من طرف موظفي كلية الحقوق والعلوم السياسية بجامعة محمد بوضياف بالمسيلة، لتنظيم ومتابعة وأرشفة غيابات الطلاب.

## الميزات

- **لوحة قيادة رئيسية (Dashboard):** تتيح عرض إحصائيات عامة (إجمالي الغيابات، غيابات الشهر) وسجل بآخر الإدخالات.
- **لوحة الموظفين (إدخال البيانات):** نموذج متكامل لإدخال بيانات الطالب وغيابه مع التوليد التلقائي للرقم التسلسلي وتاريخ التسجيل.
- **الأرشيف والسجلات:** جدول لعرض كافة الإدخالات السابقة مع إمكانية البحث بالاسم أو رقم التسجيل، وإمكانية حذف السجلات الخاطئة.
- **تصميم عصري وجذاب:** واجهة زجاجية (Glassmorphism) مريحة للعين، متوافقة مع جميع الأجهزة (Responsive Design) وباللغة العربية (RTL).
- **لا يحتاج لقاعدة بيانات خارجية:** يعتمد التطبيق على الـ LocalStorage المدمج في المتصفح لتخزين البيانات بشكل آمن ومحلي في جهاز الموظف.

## هيكل الملفات

يتكون المشروع من أربعة ملفات رئيسية فقط كما هو مطلوب:

1. `index.html`: هيكل التطبيق والواجهة الرسومية.
2. `style.css`: التنسيقات والجماليات الخاصة بالتطبيق.
3. `script.js`: المنطق البرمجي (حفظ البيانات، التنقل، توليد الأرقام، البحث).
4. `README.md`: ملف التعليمات.

## كيفية الاستخدام

1. قم بفتح ملف `index.html` باستخدام أي متصفح ويب حديث (Google Chrome, Firefox, Edge).
2. لإضافة شعارات الجامعة والكلية:
   - قم بوضع صور الشعارات في نفس المجلد.
   - افتح ملف `index.html` في محرر نصوص.
   - ابحث عن الوسوم `<img id="univ-logo" src="" alt="شعار الجامعة">` و `<img id="faculty-logo" src="" alt="شعار الكلية">`.
   - قم بتغيير السمة `src=""` لتشير إلى اسم ملف الصورة (مثال: `src="univ_logo.png"`).

## ملاحظات فنية
- التطبيق لا يحتاج لخادم (Server) لكي يعمل، يعمل مباشرة من المتصفح.
- تم تصميم التطبيق خصيصاً ليناسب الشاشات الكبيرة الخاصة بالموظفين مع توفير دعم للشاشات الصغيرة.
- تصميم وإنجاز الواجهة بناءً على طلب الأستاذ الدكتور بلواضح الطيب.
